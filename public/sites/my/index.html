Installing

  1. Open my-space-setup.exe. It installs in a few seconds, no questions asked.
  2. If Windows says “Windows protected your PC”, choose More info → Run anyway. That shows for new apps that haven't paid Microsoft for a signing certificate yet.
  3. Want the Discord card? Keep the Discord app open. That's it.
