# Hands-on checklist (about 15 minutes)

Things the automated tests can't prove: real players, real devices, two people. Tick as you go;
anything that fails, note the page, the server name and what you saw.

## On your PC, in Brave

- [ ] **animee home:** loads; "Popular on animee this week" shows (once a few people have watched); no
      cinemee card if you're signed in on both and watching something there (you get "Continue on cinemee" instead).
- [ ] **Search:** type `frirean` → Frieren is first. Click the empty box → recent searches.
- [ ] **Title page:** rate it (★ Rate it), click the trailer → it plays. Poster ＋ menu → rate from there too.
- [ ] **Watch (3ellwa):** plays, resumes where you left off, ← → jump 10 s, auto-skip intro works.
- [ ] **Watch (Rem and Ram):** each plays, resumes where you left off, and ← → jumps 10 s (Rem also in a party: pause follows).
- [ ] **Watch (Kaze):** speed button appears; set 1.5×, go to the next episode → still 1.5×.
- [ ] **Click a server that fails** → a note says which one is playing instead, and next time your old
      default is still the default.
- [ ] **Share moment** → open the copied link in a new tab → starts at that second (3ellwa or Kaze).
- [ ] **cinemee TV page** (e.g. Game of Thrones): seasons row; "Season 2" opens S2 · E1.
- [ ] **cinemee subtitles:** on a movie, "CC Your subtitles" → pick any .srt → it switches to Atlas.
      **Open Atlas's CC menu: is your file listed / shown?** (Atlas's docs only promise this on their
      premium players, so tell me if it isn't there.)
- [ ] **Account:** share your list (Whole list) → open `/u/yourname` in a private window → you see it;
      switch to Off → refresh the private window → "This list isn't shared".
- [ ] **Stats:** "your ratings" shows what you rated.
- [ ] **/admin:** "servers tried last right now" and "errors (7 days)" appear (they may be empty).

## On your phone

- [ ] Buttons and chips are comfortable to tap; the menu opens and closes.
- [ ] Sign in on both animee and cinemee → watch something on cinemee → open animee home →
      **"Continue on cinemee"** row appears.
- [ ] Start an episode on the phone, pause, open the same show on the PC → the PC offers
      "You're at … on another device: Switch to it".
- [ ] Settings → Pop-ups → turn them on, "Send a test" → a pop-up arrives. (Weekly summary: the first
      one comes Sunday 17:00 UTC.)
- [ ] Airplane mode → open the app → My list, History and Stats still open.

## With a friend

- [ ] 👥 Watch party → send the invite → they join, "2 watching".
- [ ] On 3ellwa or Kaze: you jump → they jump; on Kaze you pause → they pause.
- [ ] Next episode → they follow. Reactions float on both screens. Chat works both ways.
